# mips_processor


ეს არის წიგნის მიხედვით აწყობილი MIPS მანქანის კომპონენტები. 
System Architecture: An Ordinary Engineering Discipline Wolfgang J. Paul

ვერილოგში თითოეული კომპონენტი, ALU, memory იწერება ცალკე მოდულებში. 
მერე ამ ცაკლე მოდულებს ყველას ერთმანეთთან აკავშირებ processor მოდულში, ყველას თავისი ინპუტი და აუტპუტი აქვს და wire ბით აერთებ ერთმანეთს. 

სამწუხაროთ პროცესორ მოდულის დაფუშვა დამავიწყდა. 

თითოეული მოდულს როცა დაწერ, თან უწერ Testbench ფაილს. ეგ არის სატესტოდ, სიმულაციისთვის. 
ვთქვათ დაწერე ALU და ახლა გინდა გატესტო როგორ იმუშავებს, მართლა სწორედ უმატებს თუ არა რიცხვებს. 
შექმნი ALU ს ინსტანს ტესტბენჩში, ცვლადებს (register - ტიპის) a,b  შეუშვებ, მეხუთე ციკლზე შეუშვებ a = 2 b =3, operation = (მიმატების კოდი) და შემდეგ ციკლზე აუტპუტს ელოდები რომ 5 გახდება. 



მერე ყველა ამ კომპონენტს რომ დაწერ სპეციფიკაციის მიხედვით პროცესორს რომ ააწყობ, შენ RAM ში ტვირთავ ფაილიდან ინსტრუქციებს. აი მაგალითად programs ფოლდერი ნახე. testbench ს დაწერ უბრალოდ რომ გაუშვა პროგრამა და ყოველ ციკლს დააკვირდები. 

სიმულაციის დასარანად კაი არის iverilog და gtkwawe ერქვა ტუ სწორედ მახსოვს

თუ კარგი წიგნით ხელმძღვანელობ,  რომ გადმოაკოპირო სპეციფიკაციები იმუშავებს, რომელიმე ფაილი რომ გახსნა და ფორმულებს შეხედო, ეგ ფორმულები წიგნიდაა ეგრევე გადმოკოპირებული
